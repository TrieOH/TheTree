# Start here

- **Order:** 1
- **Summary:** What TrieOH is, and the order to read these docs in.

TrieOH builds four products. They share one repo, TheTree, because they share code and use each other.

| Product | What it does |
| --- | --- |
| IdentityX | Login, accounts, organizations, projects and API keys |
| Payssage | Payments through MercadoPago |
| Informd | Forms and their responses |
| Univents | Events: tickets, check-in, badges and certificates |

Each product is a Go API and a web app. Every app signs in through IdentityX, and Univents takes payments through Payssage.

You're reading the portal, `portal.trieoh.com`. It holds the team's docs, issues, deploys and metrics.

## Two rules to know on day one

1. Pushing a tag deploys to production. A tag looks like `payssage/v0.7.10`. Ask before you push one. Pushing to `main` deploys nothing.
2. Git hooks check your work when you commit and push. `pnpm install` sets them up. Every commit and push must pass them. When a hook fails, fix what it reports and commit again.

## Where things are tracked

- Work: Linear, team TRI, with one Linear project per product.
- Decisions and the reasons behind them: `docs/adr/` in the repo, shown in the portal under Docs, then Decisions.
