# Access

- **Order:** 2
- **Summary:** What you need to contribute, and what only the team has.

## What you need

A GitHub account. That's it.

You run everything on your machine: the APIs, their databases, file storage, and a mail catcher. Nothing you do locally touches production.

## What only the team has

| Service | What it's for |
| --- | --- |
| Cloudflare | Production: the APIs, the apps, queues and DNS |
| Neon | The production databases |
| Grafana Cloud | Traces, metrics and logs from production |
| Linear | Where the team plans work. The Issues page in this portal shows it. |
| Pushing tags to TheTree | Deploys. See [How we ship](/docs/onboarding/shipping). |

You won't need any of these to make a change. If something you're working on seems to need one, like a production log, ask the team and we'll look it up for you.
