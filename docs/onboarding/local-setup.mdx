# Local setup

- **Order:** 3
- **Summary:** Install the tools, start the four APIs, and run an app against them.

## 1. Install the tools

Install these yourself:

- Go 1.27 (check with `go version`)
- Node 26 (`node --version`)
- Docker with Docker Compose (`docker compose version`)
- [`just`](https://just.systems), a command runner (`just --version`)

Then turn on pnpm and install the rest (sqlc, golangci-lint, gotestsum, gitleaks, trivy):

```sh
corepack enable
just setup
```

`just setup` puts tools in `$(go env GOPATH)/bin` and `~/.local/bin`. If a command then says "command not found", add both to your `PATH`:

```sh
# bash or zsh
export PATH="$(go env GOPATH)/bin:$HOME/.local/bin:$PATH"
# fish
fish_add_path ~/.local/bin ~/go/bin
```

## 2. Create the env files

```sh
cp .example.env .env
for api in identityx univents payssage informd; do
  cp api/$api/.example.env api/$api/.env
done
cp front/identityx/.env.example front/identityx/.env
```

The APIs name their example file `.example.env`. The apps use `.env.example`.

Fill these in now. For secrets, `openssl rand -hex 32` prints a good value.

| File | Fill in |
| --- | --- |
| `.env` | `RUSTFS_ACCESS_KEY`, `RUSTFS_SECRET_KEY`: any values. They're the login for the local file storage. |
| `api/identityx/.env` | `POSTGRES_PASSWORD` and `IDX_POSTGRES_PASSWORD`: the same value. `ENCRYPTION_KEY`, `HMAC_SECRET`: secrets. |
| `api/univents/.env` | `HMAC_SECRET`: a secret |
| `api/payssage/.env` | `POSTGRES_PASSWORD` and `PAYSSAGE_POSTGRES_PASSWORD`: the same value |
| `api/informd/.env` | `POSTGRES_PASSWORD` and `INFORMD_POSTGRES_PASSWORD`: the same value. `IDENTITY_X_URL=http://identityx:8080`. |
| `front/identityx/.env` | `AUTH_SESSION_PASSWORD`: a secret |

Payssage, Informd and Univents also need an IdentityX project ID and API key. You'll make those in step 4, and Univents' Payssage values in step 5.

Git ignores every `.env` file.

## 3. Start IdentityX

```sh
pnpm install
just gen
just run identityx
```

- `pnpm install` installs the JavaScript packages and the git hooks.
- `just gen` builds the generated code.
- `just run identityx` starts IdentityX's database, migrates it, and runs the API.

In a second terminal, start the IdentityX app:

```sh
pnpm identityx dev
```

## 4. Make the IdentityX keys

Payssage, Informd and Univents sign in to IdentityX like any other app, so each one needs its own project and an API key. Do this once for each of them:

1. Open `localhost:3001` and sign up. The verification email lands in Mailpit, at `localhost:8025`.
2. Under Projects, create a project, such as `payssage`.
3. In the project, under Actors, create an actor of type Service.
4. Back on the project page, create an API key with that actor as its Subject.
5. Put the project ID and the key in the API's `.env`, as `IDENTITY_X_PROJECT_ID` and `IDENTITY_X_API_KEY`.

The project ID is in the page's address, after `/projects/`. Copy the key as soon as it's shown. The keys don't need any capabilities.

## 5. Make Univents' wallet

Univents takes every payment through one Payssage wallet, owned by Payssage's service actor. Start Payssage:

```sh
just run payssage
```

Then, in another terminal, create the wallet with the Payssage key from step 4:

```sh
KEY=<payssage api key>
API=http://localhost:8082

# Create the wallet. Its ID is in the response.
curl -s -X POST $API/wallets -H "X-API-Key: $KEY" -H "Content-Type: application/json" -d '{"name":"Platform Wallet"}'
WALLET=<wallet id>

# Use test payments, and take a 5% fee.
curl -s -X PATCH $API/wallets/$WALLET/sandbox -H "X-API-Key: $KEY" -H "Content-Type: application/json" -d '{"sandbox":true}'
curl -s -X PATCH $API/wallets/$WALLET/fee -H "X-API-Key: $KEY" -H "Content-Type: application/json" -d '{"fee_bps":500}'

# Send payment events to Univents. The secret is in the response.
curl -s -X POST $API/wallets/$WALLET/webhooks/endpoints -H "X-API-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"name":"univents","url":"http://univents:8080/webhooks/payssage"}'
```

Put these in `api/univents/.env`:

| Variable | Value |
| --- | --- |
| `PAYSSAGE_API_KEY` | The Payssage key, not Univents' own |
| `PAYSSAGE_WALLET_ID` | The wallet ID |
| `PAYSSAGE_WEBHOOK_SECRET` | The webhook secret |

The webhook URL uses `univents`, not `localhost`, because Payssage calls it from inside Docker. If you ever drop Payssage's database, the wallet goes with it, so you'd redo this step.

## 6. Start everything

Stop the running commands, then:

```sh
just up
```

`just up` starts a Postgres for each API and migrates it. Then it starts the four APIs, the file storage, and Mailpit.

Check that it worked: `just ps` lists the containers, and `curl localhost:8080/health` answers from IdentityX.

To work on one API, run `just run <api>` instead, for example `just run univents`. It also starts the APIs that one calls.

## 7. Run an app

```sh
cp front/univents-solid/.env.example front/univents-solid/.env
pnpm univents dev
```

The example already points at your local APIs. Replace `AUTH_SESSION_PASSWORD` with the output of `openssl rand -hex 32`.

The other apps run the same way: `pnpm identityx dev`, `pnpm payssage dev`, `pnpm informd dev`. The portal runs with `pnpm -F portal dev`.

<Callout type="warning" title="New env var?">An app only sees the variables listed in its `front/<app>/wrangler.jsonc`, even in dev. Add new ones there as well as in `.env`.</Callout>

## Ports

| Product | API | Postgres | App |
| --- | --- | --- | --- |
| IdentityX | `8080` | `5432` | `3001` |
| Payssage | `8082` | `5434` | `3003` |
| Informd | `8083` | `5435` | `3004` |
| Univents | `8081` | `5433` | `3002` |

The portal runs on `3010`, Mailpit on `8025`, and the file storage (RustFS) on `9000`, with its console on `9001`.

## Everyday commands

`<api>` is one of `identityx`, `payssage`, `informd`, `univents`.

| To | Run |
| --- | --- |
| Stop everything | `just down` |
| Go tests | `just test <api>` |
| Go lint | `just lint <api>` |
| Migrate one database | `just migrate <api>` |
| Typecheck one app | `pnpm -F <package> tsc`, with the package name from the app's `package.json` |
| Rebuild generated code | `just gen` |
