# TrieOH Style Guide

Guia visual em Solid e Tailwind, usando os componentes, fontes e tokens reais
de `@trieoh/ui-solid`. Inclui paleta com cópia de tokens, tipografia,
espaçamentos, formas e composição. O tema acompanha o sistema e permite uma
escolha manual persistida no navegador.

- Desenvolvimento: `pnpm --filter @trieoh/trieoh-style-guide dev` (porta 3006).
- Build: `pnpm --filter @trieoh/trieoh-style-guide build`.
- Deploy: tag `pages/trieoh-style-guide/v0.1.0`.
- Criação inicial: projeto Pages / Direct Upload chamado `trieoh-style-guide`,
  com branch de produção `main`.
- Endereço: `http://styles.trieoh.com/`.
- Plataforma: `https://trieoh.com`.
- Components: `https://components.trieoh.com`.

O workflow de Pages resolve a pasta pela tag, sem cadastro de projetos.
O nome do projeto e a saída de build estão em `wrangler.jsonc`.
